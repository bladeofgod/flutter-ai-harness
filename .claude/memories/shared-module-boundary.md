# 何时下沉共享模块

只有同时满足以下条件，代码才进入 Feature 共享模块：

1. 至少两个当前 Feature 需要同一行为或资源。
2. 实现不包含 Feature 专属产品规则。
3. 实现不依赖平台专属能力。
4. 目标位置不会反转包依赖方向。

否则：

- 单消费者代码留在所属 Feature。
- 平台差异通过抽象 API 和分端实现处理。
- 无业务视觉原语进入 `app_ui`。
- 协议/持久化映射进入 `app_data`，不进入 Feature shared。

共享输入或编辑行为应提供一套经过测试的 API，不允许各 Feature 分别手工操作 Selection、Token 或状态。新增共享子模块时同步更新架构文档，保证归属可发现。
