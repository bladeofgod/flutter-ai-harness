# Storage 基础能力

> 状态：安全存储、普通 KV 和 Drift 数据库生命周期均延后且未实现。

[返回基础模块索引](../infrastructure-modules.md)

本文件只覆盖跨 App 重启的数据保存。当前内存 Session、用户快照、购物车或收藏不会自动触发持久化。

## 安全存储

- 决策状态：延后。
- 实现状态：未实现。
- 目标所有者：`app_data` Adapter。
- 首个消费者：出现敏感信息跨重启持久化需求，并明确写入、读取、迁移和清除生命周期时实现。
- 采用模式：为真实消费者提供窄 Adapter，由组合根注入。
- 禁止耦合：不得用作普通偏好仓库、万能键值袋或内存 Session 的默认落盘方式，不得记录明文凭据。
- 启用验证：覆盖首次读取、写入、删除、损坏数据、升级迁移和登出清除，并验证 Android/iOS 平台配置。

## 普通 KV

- 决策状态：延后。
- 实现状态：未实现。
- 目标所有者：`app_data` Adapter。
- 首个消费者：出现非敏感、小规模配置或偏好跨重启持久化需求时实现。
- 采用模式：按消费者契约提供类型化 Adapter，明确 Key、默认值和升级行为。
- 禁止耦合：不得建立无类型全局 Map，不得存储 Token、凭据、大型结构化数据或瞬时状态。
- 启用验证：覆盖默认值、读写、删除、旧值兼容和损坏值回退。

## Drift 数据库生命周期

- 决策状态：延后。
- 实现状态：未实现。
- 目标所有者：`app_data`。
- 首个消费者：出现结构化数据跨重启保留、Schema 和迁移需求时实现。
- 采用模式：由 `app_data` 统一拥有数据库、Schema、迁移、事务和关闭生命周期，Row 通过 Mapper 转换为 Domain Entity。
- 禁止耦合：Feature 不得直接打开数据库、执行 SQL 或暴露 Row；不得为展示技术栈创建空表。
- 启用验证：覆盖全新建库、逐版本迁移、事务失败、关闭和 Row/Entity Mapper，并在同一任务建立生成同步门禁。

实现任一能力后，在本文件补充真实模块路径、公共 API、消费者、生命周期和精确验证命令。
